AI Usage
========

AI usage in this application has been kept to a minimum.

**All AI-generated content is reviewed and edited before being committed.**

AI has been used for:

* Generating commit messages, which are reviewed and corrected for accuracy.
* Debugging.
* Correcting grammar and spelling and improving documentation readability.

AI has **not** been used for:

* Generating code snippets.
* Generating documentation.
* Generating complete functions or files.
