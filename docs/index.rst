=================
Fire Search
=================

Fire Search is a simple file explorer made in Python for the terminal.

Fire Search Dependencies
========================
- python
- textual
- nerd font

Fire Search is written in `python <https://www.python.org>`_ using the `textual <https://textual.textualize.io>`_ library for it's ui.
